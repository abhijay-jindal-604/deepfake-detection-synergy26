# GPU / CUDA notes
# - torch 2.11.0+cu128 is the CUDA 12.8 build. Its compiled GPU archs (torch._C._cuda_getArchFlags(), checked
#   9 Nov 2026) are sm_75 sm_80 sm_86 sm_90 sm_100 sm_120, so it runs natively on an NVIDIA T4 (Turing, sm_75)
#   and on the RTX 5060 used for training (Blackwell, sm_120). The CUDA runtime, cuDNN 9.19 and cuBLAS come
#   inside the wheels; the machine only needs an NVIDIA driver that supports CUDA 12.x.
# - The +cu128 build lives on the PyTorch index (line below), not on PyPI. Without a GPU, the same pins also
#   run on CPU (FP32, slower).
# - timm imports torchvision, so it is needed although the script never calls it directly.
